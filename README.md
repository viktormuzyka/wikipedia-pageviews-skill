# wikipedia-pageviews-skill

Agent Skill (формат [agentskills.io](https://agentskills.io/specification)), з яким AI-агент аналізує
статистику переглядів Wikipedia і допомагає засновникам B2C-продуктів вирішувати, які теми
розвивати та якими мовами запускатися. Навичка будує графіки й формує PDF-звіт на одну сторінку.

Уся навичка — код, інструкції, тести, eval-сценарії та документація — лежить у
[wikipedia-pageviews/](wikipedia-pageviews/). Опис, встановлення, як перевірялося і roadmap:
[wikipedia-pageviews/README.md](wikipedia-pageviews/README.md).
